# 手机操控（Phone Operate）UI 设计方案 — 概览

## 做了什么
基于开发文档 `icefish/phone-operate`（Noctalia 桌面壳 + scrcpy 手机操控插件），重设计了它的三个用户界
面，目标是**美观 · 易用 · 简洁**且符合桌面壳用户习惯。

## 关键决策
- **设计系统**：暗色冷中性基底（oklch 灰阶）+ 翠绿信号色（沿用文档"绿=投屏中"语义），等宽字体专用于 IP/端口/参数值。
- **panel 重排**：设备卡片化（选中左侧翠绿轨 + 状态徽标 + 一键投屏/停止）；参数仅展示选中设备并独立成段；配对区默认收起（渐进披露）；重命名改 hover ✎ 按钮；配对表单内嵌"配对端口 vs 调试端口"提示；空状态有插图 + CTA。
- **widget**：绿/灰状态点 + 计数 tooltip（如"投屏中 · 2"）。
- **launcher**：结果卡片沿用面板语言，选中即启动。
- **约束**：不改动任何后端/IPC 逻辑（`start/stop/pair/...` 事件原样保留），仅重排与美化前端呈现。

## 交付物
- `phone-operate-ui-design.md` — 完整设计方案（上下文、原则、Tokens、三界面布局、交互改进对照、无障碍、实施备注）。
- `prototype.html` — 可交互高保真暗色原型（面板/启动器切换、设备选择、滑块实时调参、投屏切换、配对展开、重命名、空状态）。
